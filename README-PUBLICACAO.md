# AssistenteLive — pacote para GitHub Pages

A raiz contém uma página com os botões **Abrir no navegador** e **Baixar para usar no OBS**. O app está em `app/`; o ZIP está em `downloads/`.

## Conteúdo público

Esta publicação usa os IDs já configurados para leitura pública das planilhas de eventos e masterizações. Quem acessar verá os dados atuais dessas planilhas e os dados públicos do Hall. Não há credenciais privadas incluídas. Preferências, anúncios locais e áudios personalizados ficam no armazenamento local de cada navegador/OBS.

## Publicar

Publique o conteúdo desta pasta como raiz do GitHub Pages. Links são relativos para funcionar em repositórios publicados sob subcaminho (`usuario.github.io/repositorio/`).
