# AssistenteLive 0.24.43 — instalação no OBS

1. Extraia este ZIP em uma pasta permanente.
2. No OBS, adicione uma fonte **Navegador** e marque **Arquivo local**.
3. Selecione o `index.html` extraído e ajuste largura/altura da fonte.
4. Use **Interagir** para configurar. F1 abre e fecha o painel.

É necessária conexão à internet para carregar planilhas públicas, imagens e dados do Hall. As preferências, anúncios locais e sons personalizados ficam salvos no perfil local do OBS. Para transferir preferências, use a aba **Configurações** para exportar/importar JSON.
